# lauris.xyz

Personal site for Lauris Zvirbulis. Single static `index.html` (self-contained — inline CSS/JS, no build step).

## Deploy

- Hosted on Vercel project **`quickpg`** (Insrt team), serving the custom domains `lauris.xyz` + `www.lauris.xyz`.
- Git-connected to this repo, production branch `main`. Push to `main` → auto-deploys to production.
- No framework, no build command — Vercel serves `index.html` directly.

## Edit

Edit `index.html`, commit, push to `main`. That's it.
